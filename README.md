# 📅 Telegram-бот онлайн-записи клиентов

Бот для салонов красоты, барбершопов, массажистов, репетиторов и любого бизнеса с записью по времени. Клиент сам выбирает услугу, день и свободное время, а администратор сразу получает уведомление.

**Стек:** Python 3.10+, aiogram 3, SQLite (aiosqlite), FSM, asyncio

## Возможности

**Для клиента**
- Каталог услуг с ценами и длительностью
- Выбор дня (на неделю вперёд, с учётом выходных) и только **свободного** времени
- Сбор имени и телефона (кнопкой «Отправить номер» или текстом, с проверкой формата)
- Подтверждение записи
- «Мои записи» с возможностью отмены
- Автоматическое напоминание за 2 часа до визита

**Для администратора**
- Мгновенное уведомление о новой записи и об отмене
- `/today`, `/tomorrow`, `/week` — расписание
- `/cancel_booking N` — отменить запись, клиент получит сообщение
- Несколько администраторов

**Надёжность**
- Слоты учитывают длительность услуги: двухчасовое окрашивание не наложится на стрижку
- Защита от двойной записи, если два клиента одновременно выбрали одно время (транзакция `BEGIN IMMEDIATE`)
- Клиент может отменить только свою запись
- Падение отправки сообщения админу не ломает сценарий клиента

## Запуск

```bash
git clone <repo-url> && cd booking-bot
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN и свой ADMIN_IDS
python bot.py
```

## Настройка под бизнес

Всё меняется в `config.py`, без правки логики:

| Параметр | Что задаёт |
|---|---|
| `services` | Список услуг: название, длительность, цена |
| `work_start` / `work_end` | Рабочие часы |
| `slot_step_min` | Шаг сетки (30, 60 минут…) |
| `days_ahead` | На сколько дней вперёд открыта запись |
| `days_off` | Выходные дни недели |

## Структура

```
bot.py            точка входа
config.py         настройки и услуги
db.py             работа с SQLite
slots.py          расчёт свободного времени
keyboards.py      клавиатуры
reminders.py      фоновые напоминания
handlers/
  client.py       сценарий записи клиента
  admin.py        команды администратора
```
